# Maze-Solver
Project in Python

This project solves mazes that use the 'S' symbol to indicate the start and the 'E' symbol to represent the end. The maze solver will only process files containing these two characters and the '#' symbol. The program is designed to handle errors and will reject any invalid data or files.

First, the maze solver checks if the file meets the required constraints. It then verifies the presence of 'S' in the maze. Once validated, the solver traverses the maze, exploring all available paths and backtracking when necessary, until it either finds the 'E' symbol or confirms that there is no 'E' present in the maze.
